Technologies: HTML, CSS (Flexbox + Grid, media queries), JavaScript.

JavaScript features:
1. Live search box filters the book cards by title/category as you type,
   and on form submit (without reloading the page); shows a "no results" message.
2. Newsletter form validates the email with a regex and shows a success/error
   message (no server submission).
3. Explore Books button scrolls to the books section; View Details shows book
   info; View All resets the filter; hamburger menu toggles the nav on mobile.
